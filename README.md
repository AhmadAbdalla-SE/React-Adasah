## 🧐 About the Project

**Adasah** is a specialized content platform designed to bridge the gap between amateur and professional photographers. In a world where photography resources are often scattered, Adasah serves as a unified digital hub.

The platform aggregates high-quality articles, tutorials, and inspiration into a cohesive, user-friendly interface. Whether you are looking to master lighting techniques, explore portrait photography, or find the best equipment reviews, Adasah provides a curated experience to elevate your skills.

**Target Audience:** Aspiring to professional photographers, visual artists, and hobbyists.

---

## ✨ Key Features

*   **🎨 Impactful UI/UX:** A visually striking "Dark Mode" aesthetic with gradient text effects and smooth animations.
*   **📱 Fully Responsive:** Optimized for all devices—mobile, tablet, and desktop—ensuring a seamless reading experience everywhere.
*   **⚡ High Performance:** Built with Vite and React 19 for lightning-fast navigation and instant page loads.
*   **📂 Dynamic Content:** Simulates a real-world CMS using JSON data fetching to dynamically render articles and categories.
*   **🔍 Smart Navigation:** Intuitive routing between Home, Blog, and About sections without page reloads.
*   **🏷️ Categorized Learning:** Easily browse content by topics like Lighting, Portrait, Landscape, and Gear.

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

*   **Node.js** (v18 or higher recommended)
*   **npm** (comes with Node.js)

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/AhmadAbdalla-SE/React-Adasah.git
    cd React-Adasah
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  Open your browser and navigate to `http://localhost:5173` (or the port shown in your terminal).

## 🕹️ Usage

Once the application is running, you can:

*   **Navigate the Home Page:** Scroll through the featured sections to see the intro, statistics, and categories.
*   **Visit the Blog:** Click on "Blog" in the navigation bar or "Explore Articles" buttons to view the list of posts.
*   **Filter Content:** (Future Implementation) Use category cards to filter articles by topic.
